The Synthetic Monitoring agent is deploying as StatefulSet {{ include "sm-agent.fullname" . }} in namespace {{ .Release.Namespace }}.

Check that the agents are running and connected:

  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl logs -n {{ .Release.Namespace }} {{ include "sm-agent.fullname" . }}-0

The probe appears as online on the Synthetics > Probes page once an agent connects.
